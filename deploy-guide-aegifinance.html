AegiFinance

Guía de deploy para aegifinance.endevour.mx adaptada al servidor Endevour/SHEServer con Docker, Cloudflare Tunnel y Nginx Proxy Manager.

Backend listo

Internet
  ↓

  ↓

  ↓

  ↓
Container aegifinance-web :8080
  ↓

4. Preparación del servidor Ubuntu

4.1 Instalar Docker y Compose

apt update && apt upgrade -y
curl -fsSL https://get.docker.com | sh
apt install docker-compose-plugin -y
systemctl enable docker
systemctl start docker

4.2 Crear red proxy global

docker network create proxy

4.3 Crear carpeta de la app

mkdir -p /root/docker/apps/aegifinance
cd /root/docker/apps/aegifinance

5. Subir proyecto al servidor

Sube todo el contenido del proyecto AegiFinance a:

/root/docker/apps/aegifinance

Incluye especialmente:

  • AegiFinance.sln
  • src/
  • docker-compose.yml
  • .dockerignore

6. Crear archivo .env

En el servidor, copia .env.example a .env y cambia valores:

cp .env.example .env
nano .env
MSSQL_SA_PASSWORD=PonAquiUnaPasswordMuyFuerte_2026!
JWT_SECRET=PonAquiUnJwtSecretMuyLargo_Y_Seguro_2026
EXCHANGE_RATE_BASE_URL=https://api.exchangerate-api.com/v4/latest/
EXCHANGE_RATE_API_KEY=
EXCHANGE_RATE_ENABLED=false
BILLING_DAILY_RUN_TIME=02:00

7. Deploy inmediato sin problemas de cache

Para evitar problemas al actualizar, usa siempre esta secuencia:

cd /root/docker/apps/aegifinance

docker compose down --remove-orphans
docker compose build --no-cache --pull
docker compose up -d --force-recreate
docker image prune -f

Eso garantiza:

  • sin cache de build
  • imágenes base actualizadas
  • contenedores recreados
  • sin residuos de versiones anteriores

8. Verificación local en el servidor

docker compose ps
docker compose logs -f web
curl http://127.0.0.1:8088/health

Si todo está bien, deberías recibir algo similar a:

{"status":"ok","service":"AegiFinance.Web","utc":"..."}

9. Configuración en Nginx Proxy Manager

Crea un Proxy Host:

  • Domain Names: aegifinance.endevour.mx
  • Scheme: http
  • Forward Hostname / IP: aegifinance-web
  • Forward Port: 8080
  • Network: usar red docker externa proxy

Activa SSL y Force SSL desde NPM.

10. Configuración en Cloudflare Tunnel

Agrega una entrada al config.yml de cloudflared:

ingress:
  - hostname: aegifinance.endevour.mx
    service: http://npm:80

  - service: http_status:404

Luego reinicia cloudflared:

docker compose restart cloudflared
