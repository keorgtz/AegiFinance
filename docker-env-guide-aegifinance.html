AegiFinance

Guía de inyección y manejo de Variables de Entorno usando Docker Compose.

1. El archivo .env

Docker Compose busca automáticamente un archivo llamado .env en el mismo directorio donde se ejecuta el comando docker compose up. En lugar de escribir tus contraseñas directamente en el docker-compose.yml, las definimos en este archivo secreto.

IMPORTANTE: El archivo .env nunca debe subirse a Git. Para esto existe el archivo .env.example (el cual sirve como plantilla pública) y el .dockerignore / .gitignore ignoran el archivo real .env.

Cómo configurarlo en tu servidor:

# 1. Copia la plantilla pública para crear tu archivo real
cp .env.example .env

# 2. Edita el archivo real
nano .env

2. Variables soportadas por AegiFinance

Este es el listado de las variables que debes configurar dentro de tu archivo .env:

Variable en .env Descripción / Ejemplo
MSSQL_SA_PASSWORD Contraseña maestra de la base de datos SQL Server. Debe tener al menos 8 caracteres, mayúsculas, minúsculas, números y símbolos.
Ej: MiP4ssw0rd!SuperSegura
JWT_SECRET Llave criptográfica para firmar los tokens de sesión. Usa una cadena larga y aleatoria (mínimo 32 caracteres).
Ej: M1Sup3rS3cr3t0L4rg0P4r4AegiFinanc3
EXCHANGE_RATE_ENABLED true o false para habilitar/deshabilitar la obtención automática de tipos de cambio de moneda (API externa).
BILLING_DAILY_RUN_TIME Hora en la que el Worker ejecutará el motor de facturación diaria (formato HH:mm).
Ej: 02:00

3. ¿Cómo lee esto el docker-compose.yml?

Dentro de tu docker-compose.yml, Docker inyecta automáticamente los valores de .env utilizando la sintaxis de Bash ${VARIABLE}.

Para asegurar que la app funcione incluso si olvidas declarar una variable, utilizamos la sintaxis con valores por defecto ${VARIABLE:-valor_por_defecto}:

environment:
  ConnectionStrings__DefaultConnection: "Server=sqlserver,1433;Database=AegiFinanceDb;User Id=sa;Password=${MSSQL_SA_PASSWORD:-ChangeThis_Password!};TrustServerCertificate=True;"
  JwtSettings__Secret: ${JWT_SECRET:-ChangeThis_Secret_With_32_Chars}
  Billing__DailyRunTime: ${BILLING_DAILY_RUN_TIME:-02:00}

Nota técnica: En .NET, los dos guiones bajos (__) en nombres como JwtSettings__Secret le indican a la aplicación que esto sobrescribe el valor anidado en el appsettings.json bajo la sección "JwtSettings": { "Secret": "..." }.

4. Aplicar los cambios

Si alguna vez necesitas modificar una variable (por ejemplo, cambiar la hora de ejecución del Worker o habilitar el tipo de cambio):

  1. Edita tu archivo: nano .env
  2. Baja los contenedores actuales: docker compose down
  3. Vuelve a levantarlos para que Docker inyecte el nuevo archivo: docker compose up -d

Tus contenedores de AegiFinance.Web y AegiFinance.Worker arrancarán utilizando la nueva configuración inmediatamente.
