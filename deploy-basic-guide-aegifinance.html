AegiFinance

Guía básica de deploy para dar de alta subdominio, Cloudflare Tunnel, Nginx Proxy Manager y Docker en Endevour.mx.

3. Alta del subdominio en Cloudflare

  1. Entra a tu zona endevour.mx en Cloudflare.
  2. Ve a DNS.
  3. Crea un registro:
    • Type: CNAME
    • Name: aegifinance
    • Target: el hostname del tunnel o el destino que uses con Cloudflare Tunnel
    • Proxy status: Proxied
Si ya trabajas con Cloudflare Tunnel, normalmente no apuntas al IP del servidor sino al tunnel gestionado por Cloudflare.

4. Alta del hostname en Cloudflare Tunnel

En el archivo config.yml de cloudflared agrega:

ingress:
  - hostname: aegifinance.endevour.mx
    service: http://npm:80

  - service: http_status:404

Luego reinicia el contenedor/túnel:

docker compose restart cloudflared

6. Preparar carpeta de deploy en Ubuntu

mkdir -p /root/docker/apps/aegifinance
cd /root/docker/apps/aegifinance

Sube a esa carpeta:

  • AegiFinance.sln
  • src/
  • docker-compose.yml
  • .dockerignore
  • .env

7. Crear el archivo .env

cp .env.example .env
nano .env

8. Deploy inicial

cd /root/docker/apps/aegifinance
docker compose build --no-cache --pull
docker compose up -d --force-recreate

Esto levantará:

  • sqlserver
  • aegifinance-web
  • aegifinance-worker

9. Verificación

docker compose ps
docker compose logs -f web
curl http://127.0.0.1:8088/health

Debes recibir un JSON similar a:

{"status":"ok","service":"AegiFinance.Web","utc":"..."}

10. Cómo actualizar sin problemas de cache

cd /root/docker/apps/aegifinance
docker compose down --remove-orphans
docker compose build --no-cache --pull
docker compose up -d --force-recreate
docker image prune -f
Esta es la secuencia recomendada para que una actualización no te deje imágenes viejas ni cache conflictiva.
